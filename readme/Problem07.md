# Problem 7 — Course Schedule (DFS)

1. Задача: определить, можно ли пройти все курсы с учётом пререквизитов.
2. Идея: это возможно тогда и только тогда, когда в графе зависимостей нет цикла.
3. Алгоритм: DFS с тремя цветами — 0 (не посещена), 1 (в текущем пути), 2 (завершена).
4. Если из вершины находим ребро в вершину цвета 1, то найден цикл и ответ `false`.
5. Сложность: O(V + E). Файл: `src/Problem07.java`.

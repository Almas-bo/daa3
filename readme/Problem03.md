# Problem 3 — Min Cost to Connect All Points (Kruskal)

1. Задача: соединить все точки на плоскости с минимальной суммарной стоимостью; стоимость ребра — манхэттенское расстояние.
2. Идея: ищем минимальное остовное дерево (MST) полного графа.
3. Алгоритм: строим все рёбра, сортируем по весу и добавляем по очереди, если концы лежат в разных компонентах (проверка через DSU).
4. Останавливаемся, когда добавлено n − 1 рёбер.
5. Сложность: O(n² log n). Файл: `src/Problem03.java`.

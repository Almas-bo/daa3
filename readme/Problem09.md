# Problem 9 — Course Schedule II (DFS)

1. Задача: вернуть любой допустимый порядок прохождения курсов или пустой массив, если он невозможен.
2. Идея: топологическая сортировка — порядок, обратный порядку завершения DFS.
3. Алгоритм: DFS с цветами; вершина добавляется в список при завершении обработки, а при встрече вершины «в текущем пути» возвращаем пустой массив (цикл).
4. В конце список разворачивается.
5. Сложность: O(V + E). Файл: `src/Problem09.java`.

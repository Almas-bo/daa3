# Problem 8 — Course Schedule (Kahn)

1. Задача: та же, что в Problem 7 — можно ли пройти все курсы.
2. Идея: считаем входящие степени вершин (число непройденных пререквизитов).
3. Алгоритм: кладём в очередь курсы с нулевой степенью, достаём курс и уменьшаем степень его последователей; если она стала 0, добавляем в очередь.
4. Если обработаны все курсы, то цикла нет и ответ `true`.
5. Сложность: O(V + E). Файл: `src/Problem08.java`.

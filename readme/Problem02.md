# Problem 2 — Number of Provinces (DSU)

1. Задача: та же, что в Problem 1 — посчитать провинции.
2. Идея: изначально каждый город — отдельное множество, число компонент равно n.
3. Алгоритм: для каждой связи `isConnected[i][j] == 1` объединяем множества (union); при успешном слиянии счётчик уменьшается на 1.
4. Оптимизации: сжатие путей и объединение по рангу; сложность O(n² · α(n)).
5. Файл: `src/Problem02.java`.

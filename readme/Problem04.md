# Problem 4 — Min Cost to Connect All Points (Prim)

1. Задача: та же, что в Problem 3 — минимальная стоимость соединения всех точек.
2. Идея: растим дерево из одной точки, каждый раз добавляя ближайшую вершину вне дерева.
3. Алгоритм: массив `dist[v]` хранит минимальное расстояние от v до дерева; выбираем вершину с минимальным `dist`, прибавляем к ответу, обновляем соседей.
4. Для плотного (полного) графа линейный поиск минимума лучше кучи.
5. Сложность: O(n²), память O(n). Файл: `src/Problem04.java`.

# Problem 5 — Dependency Cycles (Kosaraju)

1. Задача: посчитать группы модулей, достижимых друг из друга, то есть компоненты сильной связности (SCC).
2. Шаг 1: DFS по исходному графу, вершины записываются в порядке выхода.
3. Шаг 2: обходим вершины в обратном порядке выхода по транспонированному графу; каждый запуск обхода — одна SCC.
4. DFS итеративный, чтобы не получить переполнение стека при n до 10⁵.
5. Сложность: O(n + m). Файл: `src/Problem05.java`.

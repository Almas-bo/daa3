# Problem 10 — Course Schedule II (Kahn)

1. Задача: та же, что в Problem 9 — найти порядок прохождения курсов.
2. Идея: порядок обработки вершин в алгоритме Кана и есть топологический порядок.
3. Алгоритм: очередь из вершин с нулевой входящей степенью; при извлечении вершины уменьшаем степень соседей и добавляем освободившихся.
4. Если в очередь попали не все вершины, то есть цикл и возвращается пустой массив.
5. Сложность: O(V + E). Файл: `src/Problem10.java`.

# Problem 1 — Number of Provinces (DFS)

1. Задача: по матрице смежности городов посчитать количество групп связанных городов (провинций).
2. Идея: каждая провинция — компонента связности графа.
3. Алгоритм: идём по городам; если город не посещён, увеличиваем счётчик и обходим всю его компоненту DFS (со стеком, без рекурсии).
4. Сложность: время O(n²), память O(n).
5. Файл: `src/Problem01.java`.

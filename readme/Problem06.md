# Problem 6 — Dependency Cycles (Tarjan)

1. Задача: та же, что в Problem 5 — посчитать компоненты сильной связности.
2. Идея: за один DFS для каждой вершины считаем время входа `tin` и значение `low` — минимальное `tin`, достижимое из поддерева.
3. Вершины лежат на отдельном стеке; если `low[u] == tin[u]`, то u — корень SCC, и мы снимаем со стека всю компоненту.
4. DFS итеративный, чтобы работать при n до 10⁵.
5. Сложность: O(n + m), один проход. Файл: `src/Problem06.java`.
